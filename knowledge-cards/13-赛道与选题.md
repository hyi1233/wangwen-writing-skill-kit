# 13-赛道与选题（2026年8月新增）

> 来源：网文徐掌柜2026年8月观点视频蒸馏

## 一、赛道选择原则

1. **查前人试错记录**——混搭赛道先看有没有人验证过：赛博修仙白金大神与知名作者都试过，结论"极少能写成"。标签组合要有逻辑（西游+多女主+系统经营没问题；"赛博""反经典"这类模糊标签慎用）。

2. **新人禁碰小众赛道**——围棋、足球、篮球等小众题材驾驭不了；无限流、规则怪谈极费脑子且难写好，新人不建议。

3. **西幻现状**——玄幻仙侠是大神自留地，西幻连自留地都不算，"小众被遗弃在时代浪潮里的最后狂欢"；西方滤镜碎裂导致幻想破灭。唯一还活着的是日式奇幻冒险（与西方历史文化无关）。喜欢西幻可做维多利亚/工业革命背景的本土化变体。

4. **别给自己设限**——不必死磕一个背景设定；轻小说、校园、日常恋爱冒险更稳。

## 二、规则怪谈 vs 民俗灵异

| | 规则怪谈 | 民俗灵异 |
|---|---|---|
| 核心谜底 | 违反常理的规则（谜底就在谜面上） | 民俗刻板元素给普世认知 |
| 破局方式 | 机制：设计漏洞+表面遮掩+给提示不全猜到→主角破解 | 数值强度：术法/驱魔/金手指硬破 |
| 致命缺项 | 不会玩机制=零分 | 不会渲染氛围=零分 |

- 规则不必正反颠倒，"与正常不一样"即可（晚上不许睡觉也是怪谈）。
- 灵异不给数值破局就会写成东方规则怪谈。
- 费脑赛道清单：灵异/规则怪谈/无限流/悬疑/权谋/历史（涉及机制与权斗）。

## 三、红线与禁忌

- **主角必须已成年**——未成年角色的职场/亲密/暴力内容是平台硬红线（十岁牛马需改成非人类规避）。
- 主角别是小孩：敏感+代入感差；可设小鬼帮手类角色。
- 连续重开多个开头不可取：先学方法论再动笔。
